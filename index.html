このサイトはどうやって動いていた？

HTML

「何を置くか」

HTMLでは、見出し・文章・ボタンなど、 ページの中身を作っています。

<button>無料診断を開始</button>

これは「無料診断を開始」という ボタンを作るコードです。

CSS

「どう見せるか」

CSSでは、色・大きさ・位置・余白などを決めます。

.hidden { display: none; }

このサイトでは、 表示する画面を切り替えるために使っています。

JavaScript

「何をしたらどうなるか」

JavaScriptでは、 クリックしたときの動作などを作っています。

ad.addEventListener("click", function() { ... });

これは、 「広告がクリックされたら処理を行う」 という意味です。

タイマー

カウントダウンはどう動いていた？

JavaScriptで時間を管理し、 1秒ごとに残り時間を1つずつ減らしています。

setInterval(function() { seconds--; }, 1000);
画面切り替え

このサイトの中心部分

画面を全部一度隠して、 必要な画面だけ表示しています。

広告をクリック ↓ 現在の画面を隠す ↓ 次の画面を表示

自由研究のまとめ

この作品では、 「なぜ人は危険な広告をクリックしてしまうのか」 ということを体験できるようにしました。

最初は普通のポータルサイトに見える画面から始まり、 興味を引く広告、不安をあおる表示、 カウントダウン、本人確認という流れを 模擬的に体験できるようにしています。

その後、解説・クイズ・最終シミュレーションを通して、 急かされても落ち着いて確認することの重要性を 学べる構成にしました。
